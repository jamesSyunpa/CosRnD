1. **Modify `modules/security.py`**:
    - Update `verify_access` method logic:
        - Check for `license.dat` first.
        - If `license.dat` exists and is valid (HWID matches), return `True` **immediately** without checking or deleting `setup.key`.
        - This ensures that if a user updates the `.exe` file (and keeps their existing `license.dat`), the presence of a new `setup.key` (if accidentally included or left over) won't cause issues, and the valid license takes precedence.
        - Only if `license.dat` is missing or invalid, proceed to check for `setup.key` to perform a new registration (and then delete `setup.key`).

2. **Rebuild Application**:
    - Run `build_runner.py` to compile the updated logic into the executable.

**Result**: Users can simply replace the old `.exe` with the new one. As long as their `license.dat` file remains in the same folder, the program will recognize the PC and run without needing a new `setup.key` or re-registration.
