# Implementation Plan for Persistent License Management in AppData

This plan addresses the issue where `license.dat` is lost when the program folder is replaced during updates. By moving the license file to the Windows `AppData` folder (a hidden system directory), the license will persist even if the executable or program folder is changed.

## 1. Objective
*   Store `license.dat` in a hidden folder within `%APPDATA%` (e.g., `C:\Users\Name\AppData\Roaming\CosRnD_Platform`).
*   Ensure the license file itself is hidden (Hidden Attribute) for additional security.
*   Maintain the current activation flow: `setup.key` (provided with the program) -> generates persistent `license.dat`.

## 2. Modified Logic (`modules/security.py`)
### Initialization
*   Define `app_data_path`: `os.path.join(os.environ['APPDATA'], 'CosRnD_Platform')`.
*   Create the directory if it doesn't exist.
*   Set `self.license_file` to point to this new path in AppData.
*   Keep `self.setup_flag` pointing to the program's base path (so users can simply drop `setup.key` next to the EXE).

### Activation (Verify Access)
*   **Check:** Look for `license.dat` in the AppData folder.
*   **First Run / Re-activation:**
    *   If `license.dat` is missing, look for `setup.key` in the program folder.
    *   If `setup.key` is found:
        1.  Generate `license.dat` in the **AppData** folder.
        2.  **Hide File:** Apply the "Hidden" file attribute to `license.dat` using Windows API (`ctypes`).
        3.  Delete `setup.key` from the program folder.

## 3. Benefits
*   **Updates:** You can now replace the `CosRnD_v59.exe` or the entire folder without losing the license.
*   **Security:** The license file is hidden in a system directory, reducing the chance of accidental deletion by the user.

## 4. Execution Steps
1.  Modify `modules/security.py` to implement the AppData path logic and file hiding.
